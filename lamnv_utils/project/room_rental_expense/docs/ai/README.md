# AI Docs

Tài liệu trong thư mục này dùng để lưu tri thức triển khai, thiết kế, kiểm thử và kế hoạch cho các phần việc trong repo, theo format nhiều pha để AI hoặc người đọc có thể tra cứu nhanh.

## Room Rental Expense

Tài liệu hiện có cho module `room_rental_expense`:

- [Requirements](./requirements/feature-room-rental-expense.md)
- [Design](./design/feature-room-rental-expense.md)
- [Implementation](./implementation/feature-room-rental-expense.md)
- [Testing](./testing/feature-room-rental-expense.md)

## Convention

- `requirements/`: bài toán, mục tiêu, phạm vi, tiêu chí hoàn thành
- `design/`: kiến trúc, model, quan hệ và quyết định thiết kế
- `implementation/`: những gì đã làm trong code và cách các phần nối với nhau
- `testing/`: trạng thái test hiện tại, phạm vi cần cover, checklist kiểm thử
- `planning/`: mốc triển khai, tiến hóa qua commit, rủi ro và việc tiếp theo
